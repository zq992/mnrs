这是一款以文明传承为核心的模拟人生游戏，让你用一小时的时间，亲历华夏五千年从西周到现代的历史变迁。

核心玩法：
游戏以“1分钟=1岁”的速度推进，你将经历从嗷嗷待哺的婴儿到白发苍苍老者的完整一生。成年后需要采集、种田、打猎、织布，在保证生存的同时推动部落发展。

文明演进：
开局你可能化身“女娲”，肩负传承重任，带领族人从石器时代起步，经历铁器时代、蒸汽时代，一步步迈向现代文明。每个时代都有不同的挑战和目标——从满足温饱到追求艺术与精神文明。

生命体验：
游戏不回避生命的苦难与温情，你将体验亲情、友情与爱情，感受责任与无奈，最终在死亡后化作家族树上的一个节点，为后人留下积累。

从西周的礼乐文明，到春秋战国的百家争鸣，再到秦汉大一统，直至现代——你所扮演的每个生命都将在华夏文明的画卷上留下属于自己的印记。

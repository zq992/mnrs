## 二、版本标准

### 2.1 版本号

格式 `v主版本.次版本`（如 v1.0、v0.2）：

| 位 | 变更触发 | 示例 |
|---|---|---|
| 主版本（X） | 结构性变更：章节增删、方向调整、推翻重写 | v0.x → v1.0 表示从草案到定稿 |
| 次版本（Y） | 内容修订：补细节、改措辞、修正事实错误 | v1.0 → v1.1 |

### 2.2 状态流转

```
草案(draft) → 定稿 → 终稿
```

| 状态 | 含义 |
|---|---|
| 草案 | 正在编写，待评审/待拍板 |
| 定稿 | 评审通过，决策已拍板，待审核 |
| 终稿 | 审核通过，可发布/排版 |

### 2.3 头部信息块（每份文档统一，五要素）

```
> 文档编号：0X ｜ 版本：vX.Y ｜ 日期：YYYY-MM-DD ｜ 状态：草案/定稿/终稿
> 修订说明：本次变更一句话
```

### 2.4 变更记录约定

- 每次版本变更，必须更新头部"版本 + 日期 + 修订说明"三处。
- 重大变更（主版本升级）建议在文末补"修订历史"小节，按 `vX.Y（日期）变更内容` 逐条记录。
- 跨文档口径同步：01 的结论变更（如年制、界面分层）涉及 02 的字段口径时，须同步回改 02，避免三份文档自相矛盾。

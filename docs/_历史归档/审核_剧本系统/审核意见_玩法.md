## P0（设计硬伤：不先解决，相关系统落不了地）

### P0-1 出行系统的「季」级时间，与年制主循环无任何衔接规则
- **章节**：§10 TR-3 / §10.3 / §3.1 TS-3 / §12 WR-2
- **原文**："出行时间：相邻节点 1 季（按距离/地形可调），跨多节点逐段累计"（TR-3）；"出行期间时间正常推进（年制），出行中可能错过历史事件窗口"（§10.3）；"季节降级为'年内展示'……不再作为操作/结算单元"（TS-3）
- **问题**：主循环是年制（1 年 = 1 岁 = 1 个操作周期，DL-5 还硬约束"可用行动数 ≥ 点数"），出行却以「季」计价。两种合理实现都有硬伤：
  - 若把「相邻 1 季」折成整年（跨多节点 = 连续多年）：玩家在长途出行期间多年无行动点、无法经营，纯空转，直接违反 DL-5；"错过历史事件窗口"变成纯粹的负面惩罚，玩家没得选。
  - 若出行是季级子循环：与 TS-3"季节不再是结算单元"矛盾；且出行中能否用行动点、年终结算（收成/衰老/怀孕/经济）是否照常触发、旅行与结算谁先谁后，全部未定义。
  - 战争 WR-2"出征需出行赴战场"同样被这条卡住——远征的代价无法结算。
- **建议**：把出行定义为一次"整年动作"：发起时预扣 1 年（或预扣若干年），进入"旅途"子状态——不可用行动点，但按段自动结算旅途事件与干粮消耗，并在到达/年度临界点判定；同时明确三点：①出行中能否行动；②年终结算是否暂停；③错过的历史事件窗口是否有补救（如事件改期/他国使者传报）。若不想引入子循环，就直接删掉"1 季"字样，改为"相邻节点 = 1 年"。

### P0-2 剧本「玩他的一生」定位，与剧本起点=在位期中段、时长 10~40 年 自相矛盾
- **章节**：§16.1 / §16.2 / §16.3
- **原文**："mnrs 特色 = 选历史人物玩**他的一生**：人生模拟（成长/婚姻/家族/抉择/世代传承）+ 历史事件抉择；剧本主角会生老病死、娶妻生子、死亡传承下一代"（§16.1）；"通用结构：{type, 主角, 起点（年/身份/年龄）, 目标, 专属事件[], 结局评价}"（§16.2）；"天子·幽王……犬戎灭周（切入春秋时代）"（§16.3）
- **问题**：剧本起点是"人物关键历史期的起点"（成王即位、幽王即位），不是出生；剧本时长 = 在位期。幽王约 10 年、昭王南征即死——在这些窗口里"生老病死、娶妻生子、死亡传承下一代"根本无法展开（10 年装不下一次完整的婚育+传承循环），出生年被绕过。结果同一 schema 要同时装"一生向长剧本"（成王/康王能过一生）和"事件向短剧本"（幽王/昭王是剧情关卡），而两型的**目标、传承、结局评价规则完全不同**，文档未区分。最典型的死结：幽王剧本要"传承下一代"就得续到平王+春秋，但春秋内容（争霸机制）未设计 → 剧本无法闭环。
- **建议**：明确剧本分两型，共用 schema、分开结算：①**一生向**（起点=出生或少年，走完整婚育/传承循环，结局=寿终+评价）；②**事件向**（起点=事件前夜，时长=事件窗口，无传承要求，结局=事件结果+评价）。在 schema 里加 `type / 时长 / 启用传承` 字段。并**至少先各写一个最小示例剧本**（如一生向·成王 / 事件向·昭王）来验证 schema 装得下——否则"框架+内容后话"会一直在纸面上。

## P1（高风险：不处理会显著翻车或推翻排期）

### P1-1 "数据驱动可扩展 = 加一条数据不改代码" 承诺超出实际，首批剧本需要的新机制未列清单
- **章节**：§16.2 / §16.3 / §16.6
- **原文**："剧本 = 数据文件……新增剧本 = 加一条数据、不改代码"；"天子·成王……幼年即位、周公辅政"；"天子·厉王……专利、国人暴动、共和行政"
- **问题**：成王=幼主+摄政，厉王=民心/暴动+共和（摄政变体），幽王=时代切换（东迁/殉国/投戎）——这些是自由模式里**不存在的新机制**（01 §4.2 自己写明"国家层继位机制（幼主/摄政/臣子窥鼎）不可复用领域"）。首批五个天子剧本几乎全部踩新机制，"不改代码"只在"预设开局+结局评价"意义上成立。按当前承诺排期，会出现"框架搭完，第一个剧本就写不动"。
- **建议**：措辞改为"事件内容数据化、机制增量清单化"。单独一节列出剧本引擎前置机制清单（幼主/摄政、民心与暴动、时代切换判定、结局评分表），把"新机制"从"剧本内容"里拆出来；每个新剧本过一遍"机制缺口检查"。另：§16.5 考据注仍把"武王"列入剧本人物，与 §16.3"不设武王"冲突，顺手改掉。

### P1-2 剧本可直扮天子，与「天子不可达」的范围承诺冲突，文档内部三处未对齐
- **章节**：§16.4 / 附录 C 待定#1 / 01 UI-2
- **原文**："可直接扮演天子/诸侯，绕过自由模式的晋升限制"（§16.4）；"代码……现允许诸侯→天子晋升，文档定'默认不可达'——需定夺是阻断晋升还是改文档"（附录C）；"天子……本版本默认不可达……仅作为历史窗口（如犬戎灭周）的特殊扮演关卡/终局体验存在"（01 UI-2）
- **问题**：01 UI-2 其实已预留"历史窗口扮演关卡"例外，16.4 与 01 方向一致——**这一点设计上不冲突**。但：①附录 C（成文于 v2.6 前）仍把天子可达性列为"待用户定夺"，三处口径不一，读文档的人无法判断；②更关键的是范围后果：只要幽王剧本存在，天子形态的国家经营界面（王畿/王师/朝政/时代切换）**就必须全量实现**，"天子不可达=减负/聚焦"的隐含动机被剧本系统整体绕过，§16 没有重估这个范围。
- **建议**：①在 §16 明确写死"自由模式天子仍不可达；剧本模式可直扮天子，属 01 UI-2 已预留的历史窗口例外"，并同步把附录 C #1 从"待定"改为"已定"；②把"天子国家层 + 时代切换"单列估时，塞进 P6-8 之后或作为 P7 剧本批的前置，别让剧本框架的"轻量感"掩盖这笔必做范围。

### P1-3 时代窗口（西周→春秋）对自由人生玩家实际不可达；"动态兴衰"实为年表显隐
- **章节**：§11.2 / §11.3 / §11.4 / 序 BR-2
- **原文**："随 current_year 动态显示存续国家"（NT-2）；"切换影响：……玩法重心转向诸侯争霸"（§11.4）；出生范围 "-1090 ~ -1062（文王末年）"（BR-2）
- **问题**：①自由模式单代 60 年，最晚出生 -1062 若活到百岁死于约 -962，距 -771 犬戎灭周还有近两百年；世代传承需约 8~10 代，而文档没有任何跨十代家族的长期设计（多代经济/分封衰减/遗产）。所以**时代切换玩家实际只能在幽王剧本里体验到**，"切换影响"对主模式是空话。②"动态兴衰"名不副实：NT-1/NT-2 是列国按年表显隐（scripted），若列国不可被玩家攻灭（文档无 AI 列国战争/攻灭规则），就没有真正的"动态"。③"玩法重心转向诸侯争霸"承诺了春秋机制（霸主/会盟深化/尊王攘夷），本期只到"框架+时代切换"，争霸内容零设计。
- **建议**：明确写"本期时代切换由幽王剧本承担；自由模式以列国按年表显隐为背景（不可干预）；'争霸'为远期"。若想让自由模式玩家也能经历时代推进，只能二选一：扩出生窗口覆盖中晚期，或设计家族跨代长期规则——别让玩家带着"能玩到春秋"的预期进自由模式。

### P1-4 定期朝觐义务 × 逐段出行 = 远国诸侯终生跑路，缺频率定义与"亲往/遣使"杠杆
- **章节**：§10 TR-2/TR-3 / §14 DP-1 / §14.1
- **原文**："出行 = 沿道路从节点移到相邻节点，逐段走，不能跨节点瞬移"（TR-2）；"朝觐：诸侯定期朝见天子（出行赴王畿），贡礼"（§14.1）
- **问题**：齐（临淄）到镐京若为多节点，一次朝觐往返数月数年（出行中无经营、可能错过历史窗口），而朝觐是"定期义务"。频率 × 往返耗时 × 旅途风险 三者相乘，直接决定诸侯玩家一生被"跑路"吃掉多少。当前既无频率数值，也无"遣使代觐"选项，还和 01 §2.5"诸侯委任+政令治国、不事事亲为"的精神矛盾（连朝觐都要本人亲跑）。
- **建议**：①定频率，如西周惯例"诸侯五年一朝"为默认，王命可临时加觐；②提供三档：亲往（王宠+高，耗时）、遣使代觐（王宠+低，走委任制不耗时）、称病（王宠-，触发朝觐抉择）；③把 01 §2.3 已列的朝觐抉择（称病/抗命）在 §14 补齐后果表，把"义务成本 vs 权宜代价"做成真正的抉择。

### P1-5 军功累计无衰减/上限，与 01"军功按最近 N 年计"冲突 → 可囤功直达受封
- **章节**：§12 WR-4 / 01 §5.2（P2-3）
- **原文**："军功结算 = 战胜斩获/破城 → military_merit（大胜+3/小胜+1/败-1）"（WR-4）；"军功按'最近 N 年'计（时间衰减防囤功）"（01 §5.2）
- **问题**：WR-4 的 `military_merit` 是累计值，01 §5.2 已明示军功要时间衰减防囤功，两处完全没接。若按累计：玩家年轻时长期从军（现有从军逻辑军功+1/次）+ 偶尔大胜 +3，轻松跨过受封"战功≥3"门槛，"受封 build"抄作业问题直接复发。
- **建议**：§12 军功结算统一到 01 口径——`military_merit` 存"最近 N 年窗口值"（或加时间戳、结算时滑窗求和）并设上限；受封/升士门槛引用同一窗口值。

### P1-6 战争胜负主体与作战对象未定义
- **章节**：§12 WR-2 / WR-3 / §11 NT-2
- **原文**："战争胜负 = 势力对比（_calculate_power）+ 掷骰（天时地利）"；"王命征伐 / 诸侯征召 / 家兵随征"
- **问题**：①玩家"从征"时，战役胜负应由联军 vs 敌军决定，玩家个人势力（`_calculate_power` 是家兵）只应影响个人斩获/军功——"势力对比"主体没写清。若让个人势力决定整场战役，则平民从军（无家兵）、小诸侯参战都没意义。②作战对象未定义：列国按年表存续（NT-2），玩家能否攻灭他国？若能，需要列国 AI 与攻灭规则（未设计）；若不能，战争对象只能是戎狄/淮夷/商遗民/叛周势力（如三监），文档必须写明，否则"征伐打谁"不知道。
- **建议**：定义"战役级胜负 = Σ参战方势力 + 骰子；个人斩获 = f(个人战力, 战役结果)"；给出本期作战对象表（戎狄/淮夷/叛周势力），列国攻灭标注远期。

### P1-7 纳贡双轨（经济 5% 贡赋 vs 外交纳贡）未合一；朝觐抉择（称病/抗命）无落点
- **章节**：§14 DP-3 / §3.2.4 / 01 §2.3
- **原文**："纳贡：定期缴贡赋（诸侯义务），不足受罚；纳贡额按封地大小"（DP-3）；"封田：诸侯缴 5% 贡赋（王畿），余全自留"（§3.2.4）；国家界面抉择"朝觐（纳贡/称病/抗命）"（01 §2.3）
- **问题**：§3.2.4 封田已有 5% 贡赋（经济层自动扣），§14 又设"纳贡按封地大小、不足受罚"（外交层）——两者是不是同一笔？不说明的话诸侯会被双重缴纳；合流的话"不足受罚"的判定线要落到 5% 结算上。另外 01 已把"称病/抗命"列为朝觐抉择，§14 只写了"贡礼换王宠"，抉择后果（王宠降/被伐/贬爵）完全没接。
- **建议**：明确"纳贡 = 封田 5% 贡赋的定期结算"为同一笔，定"连续 N 年未达 5% 触发处罚"的判定线；补朝觐三档抉择（亲往/称病/抗命）后果表，与 01 §2.3 对齐。

### P1-8 自由模式周天子世系更迭未定义，王宠/朝觐跨王重置规则缺失
- **章节**：§11 / §14 DP-1
- **原文**："国家数据：{name, 建立年, 灭亡年, 首都节点, 势力}"（NT-1）；"朝觐：赴王畿朝见天子，贡礼换王宠/受赏识"（DP-1）
- **问题**：自由模式玩家寿命约 60 年，期间周王必然经历成王→康王→昭王更迭。§11 只列"列国"存续，没列周天子世系；朝觐对象"周王"换代时，玩家的王宠/朝觐关系/受封记录如何处置（归零？结转？新王另计？）完全未定义。不重置则换王无游戏后果，朝觐机制静态；归零则玩家一生要多次重刷王宠，直接影响受封时机策略——这是重要决策点，必须先定。
- **建议**：§11 补"周王世系表（即位年/在位期/换代事件）"；定义换代时 王宠/朝觐/受封 的处置规则（建议：王宠按"对王畿的忠诚"部分结转，新王初始好感按玩家出身给差），并提示换代切换历史事件池。

## P2（建议：打磨项）

- **P2-1 出行交互形态**：§10 TR-2。建议"设目的地 → 自动逐段 → 途中事件自动弹出"，不要手动逐段点击；配"快马/驾车"花石提速选项，从"跑路很烦"防到"跑路有取舍"。

- **P2-3 委任加成无公式**：§15 SR-2"委任司马→军力+"加多少、缺委任减损多少都没有。建议 `委任产出 = 基线 ×（0.8 + 技能×0.1）× 忠诚/100`，空位按比例减损，与 01 §2.5"缺委任对象则产出减损"接上。
- **P2-4 传承与幼主/摄政机制未设计**：§15 SR-4 只有一句话；01 §4.2 已点名"幼主/摄政"是独立领域。成王剧本就卡在"幼年即位"上，建议先给最小摄政规则（摄政者=顾命大臣、幼主成年边界=ADULT_AGE 16）。
- **P2-5 剧本结束后衔接未定义**：§16.4。评分/结局后是否回自由模式？是否解锁内容？建议加"剧本结算 → 返回模式选择"的明确流程，避免"玩完一个剧本不知道去哪"。
- **P2-6 自由模式出生窗口只覆盖西周初 60 年**：序 BR-2 出生 -1090~-1062 意味着自由模式玩家永远只能亲历文王末~成康早期，无法亲历厉王/幽王时代。建议明示"出生窗口=早期剧本段，中晚期靠剧本/远期扩范围"，避免预期错位。
- **P2-7 剧本专属事件对系统结算的覆盖优先级未定义**：§12/§16.2。昭王南征按史必败，系统战争骰如何被剧本强制覆盖？建议事件引擎支持"剧本 override 系统结果"标记（历史强制事件与随机骰的优先级规则）。
- **P2-8 国-国联姻效果未定义**：§14 DP-4。联姻后是盟约锁定还是仅关系加分？撕毁婚盟的代价？建议 联姻→外交关系锁正 + 违约扣声望/王宠，接 §5.2.1 `marriage_links`。

## 总结

**审了几点**：针对你列的 6 大块逐一核过——历史人物剧本框架与"一生"定位（Q1/Q2）、剧本与自由模式关系（Q2）、出行不可瞬移（Q3）、国家时间线/时代窗口（Q4）、战争/外交/门客委任（Q5），每块都对照了 01《互动模式框架》的同名词条做自洽检查。

**统计**：P0 = 2 处，P1 = 8 处，P2 = 9 处。

**最重要的 3 条意见**：

1. **出行与年制的时间粒度冲突必须先解**（P0-1）。这是唯一一个"两套核心系统用互不相容的时间单位、且无衔接规则"的硬伤，出行、战争出征、朝觐三条线全被它卡住。建议出行做成"整年动作+旅途子状态"，删掉"1 季"字样。

2. **剧本"玩他的一生"的定位站不住，必须分型**（P0-2 + P1-1）。起点是"在位期中段"、时长 10~40 年，装不下"生老病死、娶妻生子、传承下一代"；幽王剧本要传承就得续到未设计的春秋。同时"加数据不改代码"对首批天子剧本（幼主摄政/国人暴动/共和/时代切换全是新机制）不成立。这直接决定 mnrs 特色是否真的区别于大周列国志，以及排期是否靠谱——建议先写一生向（成王）与事件向（昭王）两个最小示例剧本验证 schema。

3. **时代窗口与战争数值的"承诺-可达"错位要摊开写**（P1-3 + P1-5 + P1-6）。自由模式玩家单代到不了 -771，"玩到春秋"只能靠幽王剧本；"动态兴衰"实际是年表显隐；军功累计与 01 的"最近 N 年衰减"冲突会复活"受封 build"。这三处不澄清，玩家预期与文档承诺会明显脱节，且会带偏实施范围。

**Q1/Q5 两个你点名问题的直接回答**：①"选历史人物玩他的一生"作为设计意图成立，但**当前 schema 与内容表都只装得下"国政窗口"**——16.3 的天子剧本表清一色史事、无一个人生层事件，照此实现出来的天子剧本就是大周列国志的周朝面板，特色需要靠"人生抉择时刻"示例（如成王对周公的信任抉择、厉王的纳谏/专利抉择）来落实；②剧本直扮天子与"天子不可达"在 01 UI-2 里其实是自洽的（历史窗口本就被预留为例外），真正的问题是**天子国家层+时代切换因此成为必做范围，且附录 C 还停留在"待定"没同步**。

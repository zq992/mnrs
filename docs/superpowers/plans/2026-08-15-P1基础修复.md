- [ ] **Step 1: 在冷却三件套后加统一执行器**

Edit `scripts/ui/hud.gd`，在 `_mark_acted`（约 371 行）之后插入：
```gdscript
func _run_family_act(id: String, log: String, cb: Callable) -> void:
	"""统一家族动作执行器：入口查冷却，执行后打点"""
	if not id.is_empty() and not _can_act(id):
		_add_log(log)
		return
	cb.call()
	if not id.is_empty():
		_mark_acted(id)
```

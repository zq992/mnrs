## 二、Token 估算基准

| 冒烟测试 | test_gameplay 运行 | 2k-4k tokens |
| 提交 | git add/commit | 0.5k-1k tokens |

### 2.2 任务 Token 区间（经验值）

| 任务规模 | 典型场景 | 单任务 Token |
|---|---|---|
| S（0.5-1天） | 改文案、改 offset、加字段 | 15k-30k |
| M（1-2天） | 加函数、改逻辑、统一路径 | 30k-60k |
| L（3-5天） | 新面板、多文件改动、事件系统 | 60k-120k |

> 说明：这是**完成该任务全部步骤**的累计消耗，含探查/编辑/验证/提交。若一次会话做不完，按会话数均摊。

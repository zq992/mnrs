# 2026-08-15 · 玩法重设计：身份经营 + 罕见跃迁（设计文档）

> 项目：华夏模拟人生-西周篇（Godot 4.3）
> 状态：设计定稿，待用户复核后进入实施计划
> 目标：修复 4 个真实玩法问题，并把晋升系统从"刷声望点按钮"重设计为符合西周史实的"身份经营 + 罕见跃迁"

---

## 一、设计总纲

### 一句话
**你的身份大部分是命定的，但命运留了几道门**——平时好好经营这一代，当机会来临时有资格推门进去，换一个更大的天地。

### 核心转变
| | 旧（秦汉考课思路） | 新（西周分封世袭思路） |
|---|---|---|
| 晋升方式 | 声望够了点"请迁"按钮 | 世袭 / 举贤 / 受封 三大事件 |
| 可玩性 | 刷声望一路白嫖到天子 | 经营身份，机会来时接得住 |
| 国家差异 | 无 | 周王畿=京官线，诸侯国=本国权臣线 |

### 设计原则
1. **符合西周史实**：无"上朝/御史/考课"等后世概念，用"朝觐/册命/乡举里选/分封"等真实机制
2. **身份是经营出来的，不是刷出来的**：所有"跃迁"必须经大事件、掷骰、抉择，且带季/年冷却
3. **留窄门不留后门**：受封为诸侯极难但存在，给玩家一个遥不可及的梦，但不可刷

## 二、四块基础修复（方向已定）

### 2.1 事件弹窗盖住角色面板
- **问题**：`event_dialog.tscn` 的 Panel 用 `anchors_preset=15` 铺满全屏（offset 60），盖住左侧 `SidePanel`（x∈[8,212]）
- **改法**：Panel 左偏移从 60 改为 228（避让 SidePanel 右缘 212），加全屏半透明压暗背景（左侧留出面板）；或改居中弹窗
- **不动逻辑**，只动 tscn

### 2.2 家族互动无限刷（必修）
- **问题**：`_get_family_actions` 的按钮不经过 `_make_action_btn` 的冷却置灰；多数 `_do_*` 只在末尾 `_mark_acted`、入口不查 `_can_act`；`_on_gift_sibling` 完全无冷却；`_spouse_btns_for_category` 同房按钮 action_id 传空
- **改法**：统一执行器 `_run_family_act(id, log, cb)`（入口查冷却 → 执行 → 打点）；每个操作分配独立稳定冷却 ID；补 `_on_gift_sibling` 打点；同房按钮补 action_id
- **连带**：堵住"刷声望 → 晋升"的后门

### 2.3 婚姻系统
- **3a 妻妾交互**：统一"家族面板求子"与"社交同房"两套受孕判定；同房补冷却
- **3b 忠诚度自相矛盾**：所有妻妾统一模糊描述（≥80忠诚/≥60尚可/≥40有隙/<40离心），精确值仅"考察"掷骰可得；妾室补"考察/安抚"动作
- **3c 出轨增强（已选增强版）**：
  - 固定情人系统（跨季保留，亲密度+风声度两条进度，风声高则败露）
  - 妻妾忠诚随时间自然衰减，与出轨概率挂钩
  - 候选身份全换西周语境（禁"寒门秀才"等后世称谓）

### 2.4 "上朝"历史考据修正
- **问题**：`_on_attend_court` 整套"上朝/御史弹劾/位列朝班"是秦汉以后制度
- **改法**：改名"朝觐周王"，文案换"朝觐大吉！受周王册命为XX"、"朝觐失仪，被三监斥责"

## 三、晋升系统重设计（核心）

### 3.1 身份线（世袭为主）
保留 6 级社会身份（奴隶→庶人→士→卿大夫→诸侯→天子），**删除"请迁"按钮**。身份来源仅三途：

| 跃迁 | 触发 | 事件 | 代价 |
|---|---|---|---|
| **世袭** | 父亲过世 | 继承人系统（已有） | 无 |
| **举贤**（士→卿大夫） | 才学够 + 乡举里选/诸侯举荐 | 考课+举荐专属事件，**一年一次机会** | 错过再等一年 |
| **受封**（卿大夫→诸侯） | 战功/政绩 + 周王赏识 + 大机缘 | "册命大典"大事件 | 最难最荣耀，不可刷 |

**关键设计**：受封不看声望刷多少，看大事件里的抉择与机缘（不可刷，只可遇）。

### 3.2 爵位线（独立，受封才有）
- 公侯伯子男是**周王给诸侯的封号**，非个人晋升台阶
- 成为诸侯时按功绩/出身获起始爵位（子或男），此后经营封国（政绩/征伐/朝觐）逐步晋爵（男→伯→侯→公）
- 爵位决定：封国大小、兵员上限、朝见天子礼节
- **解决"升到诸侯就无事可做"的老问题**：这是"诸侯之后"的新玩法线

### 3.3 按国家分的两条成长路
| 出身 | 路线 | 终极目标 |
|---|---|---|
| 周王畿 | 在京为官 → 被周王赏识 | **受封出去当诸侯**（受封概率高） |
| 诸侯国 | 本国大夫→卿 | **本国执政/权臣**（受封基本无望） |

### 3.4 开局出身（可选，与出生国绑定）
- 周王畿：姬姓宗室 / 功臣之后 / 庶民
- 诸侯国：本国贵族 / 功臣之后 / 庶民
- 宗室=起点高+受封希望大；庶民=起点难但可能触发"奇遇举贤"

**明确**：庶民并非只能被动等彩蛋——长期政绩（声望+势力双达标）也能走举贤，只是门槛远高于士族出身；"奇遇举贤"定位为**极罕见彩蛋**（低概率额外触发），防止玩家觉得"选庶民=永无出头日"。

## 四、可选项（非本次必做）

- **新手起点财富浮动大**：开局家族遗产 `40+0~80` 石随机，运气差开局差一倍——可收敛随机区间
- **自动推进无暂停提示**：属性危险线/重要事件时自动推进应暂停提示

---

## 五、验收标准

1. 事件弹窗不再遮挡左侧角色面板
2. 家族所有互动一季只能做一次（无任何刷法）
3. 妻妾忠诚无精确值裸奔，考察/安抚有意义
4. 出轨候选无后世身份；情人有持续风险与收益
5. 晋升无"请迁"按钮，只有世袭/举贤/受封三事件
6. 诸侯国内可逐步晋爵（男→伯→侯→公）
7. 周王畿与诸侯国玩家晋升路径可感知差异
8. "上朝"等后世词汇全清除

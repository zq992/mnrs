# 2026-08-15 · 玩法重设计：身份经营 + 罕见跃迁（设计文档）

> 项目：华夏模拟人生-西周篇（Godot 4.3）
> 状态：设计定稿，待用户复核后进入实施计划
> 目标：修复 4 个真实玩法问题，并把晋升系统从"刷声望点按钮"重设计为符合西周史实的"身份经营 + 罕见跃迁"

---

## 一、设计总纲

### 一句话
**你的身份大部分是命定的，但命运留了几道门**——平时好好经营这一代，当机会来临时有资格推门进去，换一个更大的天地。

### 核心转变
| | 旧（秦汉考课思路） | 新（西周分封世袭思路） |
|---|---|---|
| 晋升方式 | 声望够了点"请迁"按钮 | 世袭 / 举贤 / 受封 三大事件 |
| 可玩性 | 刷声望一路白嫖到天子 | 经营身份，机会来时接得住 |
| 国家差异 | 无 | 周王畿=京官线，诸侯国=本国权臣线 |

### 设计原则
1. **符合西周史实**：无"上朝/御史/考课/乡举里选"等后世概念（爱马仕考据修正：**"乡举里选"本身是汉代察举术语**，改用**"大比兴贤"**（《周礼》"三年大比，考德行道艺，兴贤能"）或**"选贤与能"**），用"朝觐/册命/大比兴贤/分封"等真实机制
2. **身份是经营出来的，不是刷出来的**：所有"跃迁"必须经大事件、掷骰、抉择，且带季/年冷却
3. **留窄门不留后门**：受封为诸侯极难但存在，给玩家一个遥不可及的梦，但不可刷
4. **门要看得见**（DeepSeek 修正）：删"请迁"后必须补"晋升之门"面板，让四道门的资格清单始终可见，避免玩家迷失

## 三、晋升系统重设计（核心）

### 3.1 身份线（世袭为主）
保留 6 级社会身份（奴隶→平民→士→卿大夫→诸侯→天子），**删除"请迁"按钮**。其中"平民"拆「国人/野人」两种**平级**身份（国野之分：国人住国中、可参政、**有服兵役义务**、可多营生；野人住郊野、只能种地、**无兵役义务**），野人→国人 为平民内部身份转换、非升级。。身份来源仅三途：

| 跃迁 | 触发 | 事件 | 代价 |
|---|---|---|---|
| **世袭** | 父亲过世 | 继承人系统（已有） | 无 |
| **举贤**（士→卿大夫） | 才学够 + 大比兴贤/诸侯举荐 | 考课+举荐专属事件，**一年一次机会** | 错过再等一年 |
| **受封**（卿大夫→诸侯） | **宗室出身（硬门槛）** + 战功/政绩 + 周王赏识 + 大机缘 | "册命大典"大事件（**唯一途径**） | 最难最荣耀，不可刷；**非宗室不可受封** |

**关键设计**：受封不看声望刷多少，看大事件里的抉择与机缘（不可刷，只可遇）。

**受封硬门槛（用户定稿）**：受封（获封地、成诸侯）**仅限宗室出身**（周王畿姬姓宗室 / 诸侯国公族世族）——非宗室（功臣之后/国人）最高至卿大夫，不可受封诸侯；宗室亦须**通过"册命大典"事件获封地**才能成诸侯（宗室无封地 ≠ 诸侯）。同时**关闭"奴隶→天子"的完整晋升通道**，不存在一路刷到顶的路径。

**晋升考核制度（用户定稿，民望倒置 + 特殊技能 + 考核）**：

| 晋升 | 民望门槛（倒置）| 特殊技能 | 考核环节 |
|---|---|---|---|
| 庶人→士 | 民望≥100（最高）| 书数/礼法/射御/兵法 任一 ≥2 | 大比兴贤（三年大比，乡大夫举荐）|
| 士→卿大夫 | 民望≥60（中）| 书数/礼法 ≥3 | 举贤（诸侯/周王考察政绩）|
| 卿大夫→诸侯 | 不设民望门槛 | 战功≥3 + 势力≥60 | 册命大典（事件，宗室硬门槛）|

- **民望倒置**：越低等级晋升越看重民望——庶人无名分全靠民望翻身（门槛最高 100）；士以上已有贵族身份，民望不再是关键；受封看宗室+事件、不看民望。
- **考核制度**：晋升非"达标即升"，必经考核环节掷骰+抉择；失败保留积累但错过窗口（大比兴贤三年一次、举贤一年一次）。
- **民望口径**：民望 = 乡里民间口碑（复用 `xiangwang`），与声望/王宠三层并存。

**机缘跳级（特殊例外，不可刷，用户定稿）**：

| 跳级 | 结果 | 特殊条件 |
|---|---|---|
| 奴隶/庶人 → 大夫（卿大夫）| 破格提拔，不涉及封地 | 名望极高（≥150）+ 被周王知晓（王宠≥80）+ 机缘 |
| 奴隶/庶人 → 诸侯 | 破格受封（周王赐姓列入宗室 + 赐封地）| 同上 + 周王破格赐姓纳入宗室 |

- **不可刷（核心）**：机缘是随机事件（低概率、有封顶，最高 1%/年），非"名望达标即触发"；刷名望无法保证触发；触发后仍经考核掷骰。
- **与常规晋升并行**：常规（大比兴贤/举贤/册命）可经营可预期；机缘跳级是独立低概率彩蛋，只可遇不可求。
- **兼容性**：奴隶→诸侯需"赐姓列宗室"，不违背"受封仅限宗室"；跳级上限诸侯，仍守"关闭奴隶→天子通道"。

**关闭晋升后门**（DeepSeek + Codex 修正）：现有 `_on_ambition_plot`（暗谋举事）、`_on_seek_promotion`（觐见请命）、乡老推举等**所有其它 `promote_character` 调用点**必须一并改道——改为"加野心/实权/王宠"而非直接晋升，否则玩家可绕道仍刷。受封事件需新增 `grant_promotion`（跳过 `can_promote` 门槛，保留封地/家兵/衰减副作用）。

### 3.2 爵位线（独立，受封才有）
- **考据修正**（爱马仕）："五等爵"是战国儒家构拟的理想模型，非西周整齐制度；金文实况是爵称混杂。设计据此调整：
  - 阶梯改为完整五级 **男→子→伯→侯→公**（修正原"男→伯→侯→公"跳过"子"的矛盾）
  - **"公"定位为周王尊称的最高殊荣**（周公/召公等年高位重者的尊称），非阶梯顶点；达到"侯"已是外服大诸侯
  - 晋爵以**王命加秩**事件式呈现（"王命XX迁侯于XX"），含机缘与随机，非人人可逐级而登
- 成为诸侯时按功绩/出身获起始爵位（子或男），此后经营封国（政绩/征伐/朝觐）逐步晋爵
- 爵位决定：封国大小、兵员上限、朝见天子礼节
- **解决"升到诸侯就无事可做"的老问题**：这是"诸侯之后"的新玩法线

### 3.3 按国家分的两条成长路
| 出身 | 路线 | 终极目标 |
|---|---|---|
| 周王畿 | 仕于王庭 → 为王所重 | **受封建侯**（受封概率高） |
| 诸侯国 | 本国大夫→卿 | **本国执政/实权**（受封基本无望） |

**诸侯国"执政"线当下落地**（DeepSeek 修正，避免双重劣势）：把"执政/摄政"做成**独立实权档位**（不升 social_level，但解锁专属动作：摄政决策、调本国兵、与邻国联姻、专权事件），明确告知"此线终局为执政，换的是王畿所没有的实权与联姻优势"。

### 3.4 历史事件之门（第三道门：乱世晋升）
**补充**：除世袭、举贤/受封之外，特定历史大乱提供"突然晋升"通道——**完全符合西周史实**（如三监之乱平叛后功臣大量受封）。

| 大事件 | 时机窗口 | 玩家参与 | 可能的晋升 |
|---|---|---|---|
| **三监之乱** | 周公东征时期（前1042前后） | **家族背景事件**（见下） | 按家族立场给起点加成 |
| **周公还政/成王亲政** | 前1036~前1032 | 站队抉择：支持周公/忠于成王（16+可参与） | 忠于王室→受赏识；权争→风险 |
| **成康之治·册命大典** | 前1005~前1000 | 第1代41~46岁可参与 | 受任官职/王命加秩 |
| **昭王南征** | 前982~前977 | 第2代成年可参与 | 征伐立功 |
| **厉王专利/国人暴动/共和** | 前841~前828 | 第4~5代可参与 | 乱世站队/平乱 |
| **幽王亡国·犬戎破镐京** | 前782~前771 | 第6~7代可参与（终局） | 存亡抉择 |

**历史事件抉择分支（详细设计，用户定稿）**：每个历史窗口为抉择型事件（CD-1 结构：选项+条件+后果）。

| 事件 | 选项 | 条件 | 后果 |
|---|---|---|---|
| 三监之乱 | 家族勤王 | 无（家族背景）| 父辈军功+、获"武烈之家"起点加成 |
| 三监之乱 | 倒戈投叛 | 势力达标 | 成功→叛乱方封赏晋升；失败→降级/流放/诛族 |
| 周公还政 | 支持周公 | 无 | 周公主政期受赏识（王宠+）|
| 周公还政 | 忠于成王 | 无 | 成王亲政后受赏识（王宠+）|
| 周公还政 | 中立观望 | 无 | 风险低，两边不讨好 |
| 成康册命大典 | 接受册命 | 声望/政绩达标 | 受任官职/王命加秩 |
| 成康册命大典 | 婉拒 | 无 | 保持现状，可能错过机会 |
| 昭王南征 | 随征立功 | 成年 | 军功+（战死走意外死 CD-7）|
| 昭王南征 | 留守 | 无 | 安全，无军功 |
| 厉王专利/国人暴动 | 站队王室 | 无 | 王室胜→赏；国人胜→牵连 |
| 厉王专利/国人暴动 | 支持国人 | 无 | 国人胜→赏识；王室复辟→清算 |
| 厉王专利/国人暴动 | 中立 | 无 | 两边观望，风险低 |
| 幽王亡国（终局）| 殉国 | 无 | 壮烈结局，家族可能灭亡 |
| 幽王亡国（终局）| 东迁 | 无 | 随平王东迁洛邑，家族延续 |
| 幽王亡国（终局）| 投戎 | 无 | 叛国（高风险高回报）|

**时代窗口（西周 → 春秋，用户定稿）**：

| 时代 | 时间窗口 | 进入事件 | 时代特征 |
|---|---|---|---|
| 西周 | 前 1046 ~ 前 771 | 开局（武王伐纣）| 分封立国、宗室礼制、周室强盛 |
| 春秋 | 前 770 ~ 前 476 | **犬戎灭周·平王东迁** | 王室衰微、诸侯争霸、礼崩乐坏 |

- **时代切换**：到达幽王亡国（前 771）历史事件 → 抉择（殉国 / 东迁 / 投戎）→ 东迁则随平王入春秋时代。
- **切换影响**：列国格局剧变（周室东迁洛邑、威信大降、诸侯坐大）、历史事件池切换（春秋会盟/争霸）、玩法重心从"宗室分封礼制"转向"诸侯争霸"。
- **后续时代**（战国）作远期预留，本期只做到春秋。

**抉择原则**：每个选项后果"有得有失"（禁纯增益，见 01 §6.3）；站队类重罚（降级/流放）、日常类轻罚；成败由骰子定程度不定生死；错过窗口即关闭。

**时间窗修正（DeepSeek 发现，硬伤）**：玩家 0 岁开局（-1046 出生），三监之乱（-1042）时仅 4~7 岁，无法参与。故三监之乱**改为"家族背景事件"**：父亲/叔伯从军参与，玩家以幼子身份经历，按家族立场给起点加成（如"武烈之家"：初始军功+1、家声+20），并留"父辈军功"供 16 岁后继承用于受封门槛。首个玩家可抉择的事件让位给"周公还政"。

**关键原则**：
- 平时不可触发、不可刷，只在历史剧本特定年份窗口出现；**每代至少 1~2 个可参与窗口**（间隔 20~25 年，与一代人成年期对齐）
- 玩家做**剧情抉择**（非点按钮），抉择 + 已有声望/势力/战功**共同**决定晋升（权重约 65% 积累 + 35% 骰子）
- 错过就错过（命运之门关上），但自动推进**到事件窗口必须暂停**并给警告
- 事件机制需扩展（Codex）：`_check_prerequisites` 加 `year_range`、加 once-ever 守卫、`_apply_effects` 加 promote/demote/noble 效果类型

**三监之乱·倒戈翻盘机制**（用户补充，作为家族背景事件的分支）：
- 背景事件里，玩家家族可在叛乱中**倒戈投靠叛乱方**（武庚/管蔡）
- **势力判定**：倒戈成功率与家族势力（声望+势力值+家兵）挂钩——**势力足够大才能倒戈成功**，否则自寻死路（降级/流放/诛族）
- **翻盘回报**：倒戈成功且押对宝，叛乱方获胜后家族获封赏晋升（如武庚封赏功臣）；即使失败也是"壮烈"结局而非无声无息
- 设计意图：给高势力玩家一条**高风险高回报的叛逆路径**，让历史事件抉择有真实分量（站队决定命运）

### 3.5 田氏代齐思路（远期伏笔，非本次）
- **考据处理**（爱马仕修订）：田氏代齐是春秋末-战国初（晚于西周建立约660年），"篡位"概念直接引入属穿越——**不做篡位玩法**
- **保留机制**：权臣长期经营（民望/兵权/朝政）→ 影响力远超国君，是普世策略深度
- **西周正当化**：改成"**世卿**"（卿大夫家族世代把持朝政，西周真实现象，如鲁三桓/齐高国）+ "**受封改封**"（注意：改封=周王将封君迁到新地建侯，非权臣空降取代国君，两者别混成同一动作）
- **本次落地**：仅留文案伏笔（如受封事件埋"家族声望远播他国"），权臣经营线整体**远期再做**

### 3.6 开局出身（可选，与出生国绑定）
- 周王畿：姬姓宗室 / 功臣之后 / 国人 / 野人
- 诸侯国：本国贵族（公族/世族） / 功臣之后 / 国人 / 野人
- **宗室 = 唯一可受封**（受封硬门槛）；功臣之后/国人 = 封顶卿大夫，不可受封诸侯；国人 = 起点难但可能触发"奇遇举贤"

**用词考据**（爱马仕）：西周是国/野之分，"**国人**"（有参政、充军资格）比"庶民"更精确；"庶民"偏后世平民义。

**明确**：国人并非只能被动等彩蛋——长期政绩（声望+势力双达标）也能走举贤（大比兴贤），只是门槛远高于士族出身；"奇遇举贤"定位为**极罕见彩蛋**（低概率额外触发），防止玩家觉得"选国人=永无出头日"。
